# latchtag

Latch digests and tag fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/latchtag/

## Install / run

```bash
git clone https://github.com/theworker02/latchtag.git
cd latchtag
node src/cli.js
node --test
```
